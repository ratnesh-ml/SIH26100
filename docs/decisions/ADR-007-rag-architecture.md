# ADR-007: Air-Gapped Retrieval-Augmented Generation (RAG) Copilot

**Status:** Accepted  
**Date:** September 2026  
**Deciders:** Core Architecture Team, SIH26100  

---

## 1. Context
Procurement officers frequently need to ask contextual questions during bid scrutiny (e.g. *"What is the warranty period offered by Meridian Pumps?"* or *"Does Kaveri's technical data sheet specify API-610 11th edition compliance?"*). While LLMs excel at conversational question-answering over text, public PSU deployments are subject to strict data security constraints: bidder technical IP, proprietary manufacturing drawings, and pricing estimates must never be leaked to public cloud AI endpoints.

## 2. Decision
We implement a **Dual-Mode, Air-Gapped RAG Copilot Architecture** (`backend/routers/copilot.py`, `pipeline/rag/retriever.py`):
1. **Local Vector / Semantic Index:** Document chunks are extracted, cleaned, and embedded locally using lightweight sentence transformers or TF-IDF BM25 fallback.
2. **Deterministic Context Assembly:** Queries retrieve the top-$k$ relevant text chunks with exact document and page references.
3. **Dual Generation Modes:**
   - **Local / Air-Gapped Mode (Default):** Returns structured excerpt summaries with exact document citations directly from the local retrieval index without calling any external API.
   - **External LLM Mode (Optional Feature Flag):** If explicitly configured by the PSU administrator (`LLM_ENABLED=true` with private endpoint), passes redacted context to an on-premises or enterprise LLM instance.

## 3. Reason
- **Zero Data Leakage:** Bids contain confidential commercial information. By default, zero bytes of text leave the host container or server.
- **Reliable Competition Demonstration:** Operates seamlessly on a laptop without Wi-Fi or API rate-limit interruptions.
- **Verifiable Citations:** Every answer generated by the Copilot is accompanied by clickable citations linking directly to the source PDF pages.

## 4. Alternatives Considered
- **Direct OpenAI / Anthropic Public API Calls:**
  - *Rejected:* Unacceptable for defence and PSU procurement under CERT-In guidelines; introduces latency, network dependency, and recurring API cost.
- **Heavy On-Device 70B Parameter LLMs:**
  - *Rejected:* Requires dedicated high-end GPUs (e.g. NVIDIA A100/H100), making local development and standard hackathon evaluation impossible.

## 5. Consequences
- **Positive:** Compliant with national data sovereignty mandates; fast response times; zero external API dependencies.
- **Negative:** Local extractive mode provides factual snippet synthesis rather than creative free-form prose generation.
